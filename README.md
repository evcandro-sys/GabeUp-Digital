# GabeUp Digital — Soluções Digitais para Negócios Locais

Biosite premium, responsivo e de alta performance desenvolvido para a **GabeUp Digital**, com foco em conversão e direcionamento direto para o WhatsApp.

---

## 🚀 Como subir para o GitHub

O repositório local Git já foi inicializado e o primeiro commit já está preparado na branch `main`.

Basta criar um repositório no seu GitHub (ex: `gabeup-digital`) e executar no terminal:

```bash
# 1. Vincule ao seu repositório no GitHub (substitua pelo link do seu repositório)
git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git

# 2. Envie os arquivos para a branch principal
git push -u origin main
```

## 🛠️ Comandos do Projeto

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento (porta 3000)
npm run dev

# Gerar build de produção otimizado para deploy
npm run build

# Testar o preview da versão compilada localmente
npm run preview

# Verificar tipagem TypeScript
npm run lint
```

## 🌐 Deploy & Preview no GitHub Pages / Vercel / Netlify

O `vite.config.ts` já está configurado com `base: './'`, permitindo que o site funcione perfeitamente em:
- **GitHub Pages** (mesmo em subpastas `https://usuario.github.io/repositorio/`)
- **Vercel**
- **Netlify**
- **Cloudflare Pages**
- **Qualquer hospedagem estática**

### Opção 1: GitHub Pages automático com GitHub Actions
Ao subir para o GitHub, você pode ativar o GitHub Pages em **Settings > Pages > Build and deployment > Source: GitHub Actions** e escolher o template padrão de Vite/Static HTML.
